NGU Edge Product Roadmap

From discipline to full profitability optimization.

Current State — Live Foundation

  • Execution journal + P&L calendar + account filtering
  • Emotional tagging, execution score, stability score, streaks
  • 90-day seasons, XP, league progression, goal system
  • Prop/evaluation tracking, payouts, spend vs payout
  • Capital efficiency + 90-day forecast + shareable stat card

Phase 2 — Optimization Refinement (3–6 months)

  • Execution Replay 2.0 pattern detection
  • Enhanced emotional correlation insights
  • Smarter 90-day forecast modeling
  • Weekly structured performance summaries
  • Refined drawdown recovery analytics

Phase 3 — Structured Social Layer (6–9 months)

  • Public execution-based profiles
  • Shareable season summary cards
  • Private invite-only execution leagues
  • Anonymous discipline-based rankings
  • Operator rating system

Phase 4 — Advanced Profitability Engine (9–12 months)

  • Multi-account scaling planner
  • Risk modeling and failure probability engine
  • Capital allocation optimization
  • Deep multi-season performance archive
  • Structured operator credibility system

12–24 Month Vision

NGU Edge evolves into a performance hub, discipline benchmark, social execution network, and capital optimization engine.

Core Principle: discipline stays free, structure stays accessible, intelligence deepens over time.
